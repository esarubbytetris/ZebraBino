# ZebraBino

### Tecnologia para a segurança dos motoristas de caminhões

O ZebraBino é um projeto de tecnologia voltado à segurança
dos profissionais do transporte rodoviário de cargas.

## Nossa missão

Contribuir para viagens mais seguras, apoiando o motorista
com informações relevantes para suas decisões nas estradas.

## O projeto

O ZebraBino encontra-se em desenvolvimento.

Seu objetivo é explorar soluções digitais que contribuam
para a segurança, a informação e o apoio ao caminhoneiro
durante suas viagens.

## Desenvolvimento e colaboração

Este repositório apresenta publicamente o projeto.

O desenvolvimento técnico, os protótipos e a documentação
interna são mantidos em ambiente privado.

Sugestões e oportunidades de colaboração podem ser
discutidas com o mantenedor.
